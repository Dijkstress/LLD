Connect Four is a two-player connection game where the players take turns placing their pieces in a 7x6 grid. The first player to connect four of their pieces in a row, column, or diagonal wins.

entities
    - player
    - game
    - board

    Game is responsible to create players and boards and other game functionality like did anyone win
    Board is responsible for placing moves and let the game know has anyone won
    Player is responsible for nothing so far but player color

Class Design

    class Game:
        board : Board

        currentPlayer : Player

    class Board:
        row : 6
